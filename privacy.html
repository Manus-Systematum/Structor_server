Privacy

Structor collects nothing. This page says what that means in detail, because a claim that short is worth checking.

  • There is no account. Nothing identifies you to anyone, including us.
  • There is no analytics, no crash reporting, no advertising and no third-party SDK of any kind. The app's entire dependency list is a database engine, a file-path helper and a package-version reader.
  • Your armies, battles and settings are written to a database file inside the app's own storage on the device. Deleting the app deletes them.
  • Nothing is uploaded. The app makes one kind of request, and it asks for rules data: a small list of what the current data is, read from structor.systematum.net when the app starts, and then only the files named in it that the app does not already have. It carries no account, no identifier and nothing about your armies — it is the same kind of request a browser makes for a page.
  • The server that answers is ours, and it sees what any web server sees: the address the request came from, the file asked for, and the time. Those lines are kept while the container that wrote them runs and are read only to see whether the data is being served correctly. Cloudflare sits in front of it and sees the same.
  • Nothing is sold or shared, because nothing is collected in the first place.

Nothing here is collected from you: no account, no identifier, nothing linked to a person, and nothing used to track anyone across apps or sites. What the server records is the request, not the reader.

Two details worth stating

  • Importing a list is a paste into a text field. The app never reads the clipboard itself — it contains no clipboard code at all; iOS puts the text in when you tap paste. What you paste goes into the local database and nowhere else.
  • The rules updates named above arrive as data, not as new versions of the app. Games Workshop corrects points and wording more often than an app can be released, so a correction is published as a file and the app reads it. Until 28 August 2026 this page said the app made no requests at all, which was true of every version before that one and stopped being true when the data was published; the sentence above replaced it.
